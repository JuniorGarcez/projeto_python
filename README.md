# Batalha RPG em Python

Jogo de batalha por turnos no terminal, feito para praticar Programação Orientada a Objetos em Python: herança, encapsulamento (atributos privados com getters) e sobrescrita de métodos.

## Como jogar

Requisito: Python 3.6 ou superior. Não há dependências externas.

```bash
cd projeto
python3 main.py
